1. 여행 상품은 사이트에 올라가지 않습니다
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

여행 일정을 netlify/functions 폴더 안에 둡니다.
이 폴더의 파일은 서버 안에서만 돌아가고 손님에게 파일로 내려가지 않습니다.
주소를 아는 사람도 열어 볼 수 없습니다.

  손님 화면(index · shop · product)   여행 상품 안 보임
  사이트주소/assets/tours.js          그런 파일 자체가 없음
  대쉬보드 [여행사] 탭                게시 열쇠를 넣은 대표님만 보임
  쓰레드 글                           서버가 꺼내 씁니다

사진도 마찬가지입니다. 여행 사진은 쇼핑몰에 한 장도 올라가지 않습니다.
지금 설정은 "사진 없이 글만" 입니다.
나중에 회사 홈페이지 같은 여행사 쪽에 사진을 올리시면,
그 전체 주소(https:// 로 시작)를 대쉬보드에 적어 주시면 됩니다.
쇼핑몰 안 경로를 적으시면 대쉬보드가 막고, 서버도 무시합니다.

2. 올리는 자리
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  sw.js                                   → 맨 위 폴더에 덮어쓰기

  netlify/functions/threads.js            → netlify/functions 에 덮어쓰기
  netlify/functions/tours-data.js         → netlify/functions 에 넣기 (새 파일)
  netlify/functions/threads-tour-cron.js  → netlify/functions 에 넣기 (새 파일)

넣으신 뒤 Netlify 에서 배포하시면 됩니다.

※ assets 폴더에는 여행 관련 파일이 하나도 없습니다. 그게 정상입니다.
※ tours-data.js 를 assets 폴더로 옮기지 마십시오. 옮기면 누구나 열어 볼 수 있게 됩니다.

3. 쓰레드 여행사 계정 — 순서대로
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

앱은 새로 만들지 않습니다.
지금 있는 "Mediterraneo Threads" 앱에 계정 하나만 더 붙이는 것입니다.

 (1) 여행사용 인스타그램 계정을 준비합니다. (쇼핑몰 계정과 다른 계정)
 (2) 그 계정을 프로페셔널 계정으로 바꿉니다. — 휴대폰 인스타그램 앱에서만 됩니다.
     설정 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환
 (3) 그 계정으로 threads.net 에 가입합니다.
 (4) developers.facebook.com → 내 앱 → Mediterraneo Threads → 앱 역할 → 역할
     [사람 추가] → Threads 테스터 → 그 계정 이름을 넣습니다.
 (5) 그 계정으로 threads.net 에 로그인한 채로
     계정 설정 → 웹사이트 권한 → 초대를 수락합니다.
     ※ 빠뜨리면 나중에 "has not accepted the invite" 오류가 납니다.
 (6) 개발자 페이지 → 이용 사례 → Threads API 액세스 → 맞춤 설정
     → 사용자 토큰 생성기 → 그 계정 옆의 [토큰 생성] → 복사 아이콘으로 복사
 (7) 사용자 번호 확인 — 주소창에 넣고 열기
     https://graph.threads.net/v1.0/me?fields=id,username&access_token=붙여넣기
     → {"id":"...","username":"..."} 의 id 가 사용자 번호입니다.
 (8) 토큰을 60일짜리로 바꾸기
     https://graph.threads.net/v1.0/refresh_access_token?grant_type=th_refresh_token&access_token=붙여넣기
     → expires_in 이 500만 쯤 나오면 60일짜리입니다. 여기서 나온 토큰을 씁니다.
 (9) Netlify → Site configuration → Environment variables → Add a variable
       THREADS_TOUR_USER_ID   (7)번의 id
       THREADS_TOUR_TOKEN     (8)번의 토큰
(10) Deploys → Trigger deploy → Deploy site
     ※ 환경변수는 새로 배포해야 서버가 읽습니다. 빠뜨리면 계속 "없음" 입니다.
(11) 대쉬보드 [여행사] 탭 → [준비 상태]
     사용자번호 · 토큰 · 열쇠가 셋 다 "있음" 이면 끝입니다.

※ 토큰과 앱 시크릿은 저에게 보내지 마세요. 넷리파이에만 넣으시면 됩니다.
※ 토큰이 들어간 주소는 화면 캡처하지 마시고, 다 쓰신 뒤 브라우저 기록에서 지워 주세요.

다 넣으신 뒤 [반영·배포] 에서 올리시면 그때부터 돌아갑니다.
올라가는 파일은 netlify/functions/tours-data.js 하나뿐입니다.

영어도 같이 올리기로 해 두셨다면(기본값은 한국어만),
영어 이름을 안 적어 둔 일정은 영어 차례에 건너뜁니다.
한글이 섞인 영어 글이 나가지 않도록 일부러 그렇게 해 두었습니다.
그런 일정이 있으면 탭 위쪽에 노란 칸으로 알려 드립니다.

※ 서버에서 일정을 못 받아 왔을 때는 아무것도 내보내지 않습니다.
  빈 목록으로 원래 일정을 덮어쓰는 사고를 막으려고 그렇게 해 두었습니다.
