3. 쓰레드 여행사 계정 만들기 — 순서대로
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

쇼핑몰 때와 똑같은 길입니다. 앱은 새로 만들지 않습니다.
지금 있는 "Mediterraneo Threads" 앱에 계정 하나만 더 붙이는 것입니다.

 (1) 인스타그램에서 여행사용 계정을 하나 더 만듭니다.
     휴대폰 인스타그램 앱 → 프로필 → 계정 추가 → 새 계정 만들기
     이름은 유포리아투어 쪽으로 (예: euforiatour_kr)

 (2) 그 계정을 프로페셔널 계정으로 바꿉니다.
     휴대폰 앱에서만 됩니다. 설정 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환

 (3) 그 계정으로 threads.net 에 가입합니다. (인스타그램 계정으로 로그인)

 (4) developers.facebook.com → 내 앱 → Mediterraneo Threads → 앱 역할 → 역할
     [사람 추가] → Threads 테스터 → 방금 만든 계정 이름을 넣습니다.

 (5) 그 계정으로 threads.net 에 로그인한 채로
     계정 설정 → 웹사이트 권한 → 초대를 수락합니다.
     ※ 이걸 빠뜨리면 나중에 "has not accepted the invite" 오류가 납니다.

 (6) 다시 개발자 페이지 → 이용 사례 → Threads API 액세스 → 맞춤 설정
     → 사용자 토큰 생성기 → 그 계정 옆의 [토큰 생성]
     → 나온 토큰을 복사 아이콘으로 복사합니다. (손으로 긁으면 잘립니다)

 (7) 사용자 번호를 확인합니다. 주소창에 아래를 넣고 여시면 됩니다.
     https://graph.threads.net/v1.0/me?fields=id,username&access_token=붙여넣기
     → {"id":"...","username":"..."} 에서 id 가 사용자 번호입니다.

 (8) 토큰을 60일짜리로 바꿉니다.
     https://graph.threads.net/v1.0/refresh_access_token?grant_type=th_refresh_token&access_token=붙여넣기
     → expires_in 이 500만 쯤 나오면 60일짜리입니다. 여기서 나온 토큰을 씁니다.

 (9) Netlify → Site configuration → Environment variables → Add a variable
     두 개를 넣습니다.

       THREADS_TOUR_USER_ID   (7)번의 id
       THREADS_TOUR_TOKEN     (8)번의 토큰

(10) Deploys → Trigger deploy → Deploy site
     ※ 환경변수는 새로 배포해야 서버가 읽습니다. 이 단계를 빠뜨리면 계속 "없음" 입니다.

(11) 대쉬보드 [여행사] 탭 → [준비 상태] 를 눌러
     사용자번호 · 토큰 · 열쇠가 셋 다 "있음" 이면 끝입니다.

※ 토큰과 앱 시크릿은 저에게 보내지 마세요. 넷리파이에만 넣으시면 됩니다.
※ 토큰이 들어간 주소는 화면 캡처하지 마시고, 다 쓰신 뒤 브라우저 기록에서 지워 주세요.

한글이 섞인 영어 글이 나가지 않도록 일부러 그렇게 해 두었습니다.
그런 일정이 있으면 [여행사] 탭 위쪽에 노란 칸으로 알려 드립니다.

  쇼핑몰 계정   월 · 수 · 금  저녁 8시
  여행사 계정   화 · 목       저녁 8시

일부러 겹치지 않게 두었습니다. 한 주에 다섯 번, 서로 다른 계정에서 나갑니다.

요일을 바꾸시려면 netlify/functions/threads-tour-cron.js 의 이 한 줄만 고치시면 됩니다.

  export const config = { schedule: '0 11 * * 2,4' };
                                    │ │       └ 요일 (0=일 1=월 2=화 …)
                                    │ └ 시 (세계표준시). 한국 시각에서 9를 뺀 값입니다.
                                    └ 분
