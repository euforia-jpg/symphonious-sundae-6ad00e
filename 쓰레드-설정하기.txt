쓰레드(Threads) 자동 게시 — 설정 순서


■ 0. 먼저 파일을 올립니다 (순서가 중요합니다)

  admin.html
  sw.js
  assets/policy.js                  ← 문구 8개가 여기 들어 있습니다
  netlify/functions/threads.js      ← 새 파일
  netlify/functions/threads-cron.js ← 새 파일
  netlify/functions/fx.js           ← 지난번 개선판 (아직 안 올리셨으면)

  * assets/data.js 와 assets/img/ 는 넣지 않았습니다. 절대 같이 올리지 마십시오.
  * 파일을 올리기 전에 대쉬보드에서 [반영·배포] 를 누르지 마십시오.
    낡은 policy.js 를 읽은 채로 배포하면 문구가 날아갑니다.
    (그런 일이 생겨도 이 파일을 다시 올리시면 됩니다)


■ 1. 쓰레드 쪽 준비 (사장님이 직접 하셔야 하는 부분입니다)

  1) 쓰레드 계정을 프로페셔널(비즈니스) 계정으로 바꿉니다.
  2) developers.facebook.com 에서 앱을 하나 만들고 "Threads API" 를 붙입니다.
  3) 권한 두 가지를 신청합니다 — threads_basic, threads_content_publish
     · Tech Provider 인증에 약 1주,
     · 권한 심사에 2~4주 걸립니다. 먼저 넣어 두시는 게 좋습니다.
     · 심사가 끝나기 전에도 "내 계정"으로는 시험이 되는 경우가 많습니다.
       되는지 안 되는지는 아래 5번에서 바로 확인됩니다.
  4) 장기 토큰(long-lived access token)을 받습니다. 60일짜리입니다.
     → 60일마다 갱신해야 합니다. 달력에 55일 뒤로 알림을 걸어 두십시오.
  5) 쓰레드 사용자 번호(user id)를 적어 둡니다.


■ 2. 넷리파이에 값 세 개 넣기

  Netlify → 이 사이트 → Site configuration → Environment variables → Add

    THREADS_USER_ID     쓰레드 사용자 번호
    THREADS_TOKEN       장기 토큰
    THREADS_HOOK_KEY    아무도 못 맞출 긴 문자열 (12자 이상, 직접 아무렇게나 만드세요)

  * 토큰은 넷리파이 안에만 있습니다. 손님 화면에도, 대쉬보드에도 내려가지 않습니다.
  * 값을 넣은 뒤에는 한 번 다시 배포(Deploys → Trigger deploy)해야 반영됩니다.


■ 3. 확인

  대쉬보드 → [쓰레드] 탭

    [준비 상태]            세 값이 다 "있음" 으로 나오면 됩니다.
    [오늘 나갈 글 미리보기]  진짜 글을 만들어 보여만 줍니다. 올리지 않습니다.
    [지금 하나 올리기]      열쇠를 넣고 누르면 진짜로 올라갑니다. 처음 한 번만 해 보세요.


■ 4. 그 뒤로는

  월·수·금 저녁 8시(한국 시각)에 알아서 하나씩 올라갑니다.
  요일·시각을 바꾸시려면 netlify/functions/threads-cron.js 의
    export const config = { schedule: '0 11 * * 1,3,5' };
  이 한 줄만 고쳐서 다시 올리시면 됩니다. (UTC 기준 — 한국 시각에서 9시간 빼기)


■ 어떻게 고르는가

  · 숨김 / 재고 0 / 가격 없음 / 사진 없음 인 상품은 건너뜁니다.
  · 남은 상품을 번호순으로 한 바퀴 돌고, 문구는 다른 보폭으로 돌립니다.
    지금 상품 5개 · 문구 8개면 같은 상품은 약 12일마다 돌아오고,
    그때 문구는 반드시 다른 것이 붙습니다. (39회를 돌려 확인했습니다)
  · 원화는 그날 환율로 다시 계산합니다.
  · 글은 500자를 넘지 않게 잘립니다.


■ 스팸으로 걸리지 않으려면

  같은 상품을 같은 문구로 되풀이하면 계정이 제한될 수 있습니다.
  상품이 늘수록 안전해집니다. [쓰레드] 탭의 "한 상품이 다시 나오기까지" 숫자를
  가끔 봐 주시고, 사람 손으로 쓴 글(먹는 법, 현지 이야기, 사진)을 사이사이
  섞어 올리시면 가장 좋습니다.

  문구를 고치실 때 상품에 없는 사실을 적지 마십시오.
  자리표({name} {tag} {brand} …)만 쓰시면 틀릴 일이 없습니다.
