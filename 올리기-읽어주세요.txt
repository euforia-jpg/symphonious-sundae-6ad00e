       루트 15개  : index / shop / product / brands / brand / cart /

■ 이번에 새로 들어간 것
  - 첫 화면 오른쪽에 자동으로 그려지는 스케치
      검수(병+돋보기) → 포장(상자) → 항공(궤적+비행기) → 집
      선이 차례로 그려지고, 5초 두었다가 지우고 다시 그립니다.
      궤적의 점선은 계속 집 쪽으로 흐릅니다.
      가로 900px 이상(컴퓨터 화면)에서만 나옵니다. 휴대폰에서는 안 나옵니다.
      글자 4개(검수·포장·항공 직송·집 앞까지)는 7개 언어로 번역돼 있습니다.

■ 그 앞서 들어간 것
  - 상품 순서 섞기 + 카드 등장 효과
  - NEW(등록일 자동) / BEST(이번 달 판매 1위 자동) + 배지 반짝임
  - 사진 오른쪽 아래 "이번 달 N개 판매" (0에서 올라감, 0이면 안 보임)
  - 국제배송비 = kg 올림 × 15유로, 최소 1kg
  - 카카오톡 문의 단추 (pf.kakao.com/_BSxggn/chat)
  - 이용안내(결제·배송·취소환불) / 배송 조회 페이지
  - 장바구니 결제수단 선택 + 카드결제 자리(준비중)
  - 없어진 상품이 장바구니에 남아 배송비만 붙던 문제 수정
  - 클릭할 때마다 사진이 깜빡이던 문제 수정
