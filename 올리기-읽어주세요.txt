■ 무엇이 달라지나 — 환율

  전에는 자동으로 바뀌는 장치가 아예 없었습니다.
  [오늘 환율 자동으로 받아오기] 를 사장님이 누르고 → [적용] → [반영·배포] 까지
  해야만 손님 화면 원화가 바뀌었습니다. 그래서 8월 27일 값에 멈춰 있었습니다.

  이제는 이렇게 돕니다.
    1. 손님이 사이트를 열면, 하루에 딱 한 번 우리 서버에 오늘 환율을 물어봅니다.
    2. 우리 서버(netlify/functions/fx.js)가 하나은행 매매기준율을 받아 옵니다.
       - 손님 브라우저가 하나은행 쪽을 직접 부르면 막힙니다. 그래서 서버가 대신 갑니다.
       - 하나은행 쪽이 안 되면 다른 곳으로 자동 대체하고, 화면에 실제 출처를 적습니다.
    3. 거기에 사장님이 정한 판매 버퍼(지금 3%)를 얹어서 원화로 보여 줍니다.
    사장님이 아무것도 안 하셔도 매일 따라갑니다.

  안전장치
    - data.js 에 박힌 환율은 "바닥값"입니다. 못 받아오면 그 값을 그대로 씁니다.
    - 받아온 값이 바닥값과 15% 넘게 차이 나면 이상한 값으로 보고 버립니다.
      (바깥 API 가 잘못된 숫자를 뱉어도 손님 화면 가격이 튀지 않습니다.)
    - 그러니 바닥값도 가끔은 손봐 주시는 게 좋습니다. 두 달에 한 번쯤,
      [환율] → [오늘 환율 자동으로 받아오기] → [적용] → [반영·배포].

  값을 붙들어 두고 싶을 때
    환율이 크게 튀는 날에는 [환율] → 기준환율을 직접 넣고 [적용] 하면
    그 값으로 못박히고 자동 갱신이 멈춥니다. 되돌리려면 [원래대로].

  [환율] 탭을 열면 이제 "오늘 손님이 보는 값"이 큰 숫자로 나옵니다.
  아래 미리보기 표의 원화도 오늘 값으로 계산해서 보여 줍니다.
